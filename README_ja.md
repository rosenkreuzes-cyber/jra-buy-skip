# JRAダート3連複・4頭BOX　発走前オッズ収集と買う／見送る研究

## 起動

```bash
pip install -r requirements.txt
streamlit run app.py
```

予測CSV（1レースの馬番・`top3_probability` または `model_rank`）をアップロードして、netkeibaの12桁レースID、開催日、発走時刻を指定してください。
「単勝と3連複を一括取得して判定・保存」を押すと、単勝（type=1）と3連複（type=7）のオッズを取得します。

モデル予測CSVを指定すると**当該時点の単勝人気上位7頭の中からモデル確率上位4頭を選択**します。別アプリですでに4頭を確定している場合は、直接馬番を入力できます。**同一レースの4頭は初回保存時に固定**され、その後のオッズ再取得では変更しません。

## 記録と判定

- 各レースの選択4頭、単勝人気、3連複4組のオッズ、全3連複オッズ、取得日時、オッズ配信時刻、予測CSVのSHA-256を記録。
- 取得が発走5分前より遅ければ時刻未検証として記録。API配信時刻が欠けている、古い、発走5分以内、手動JSON読込でも時刻未検証。
- 参考用のBOX的中確率が与えられない場合は「判定保留」。4組とも4倍以下なら確率によらず「配当不足・見送り」。
- 参考的中確率がある場合、的中組がどの4組か分からないことを考慮して、**期待回収倍率の上下限**を示す。例: 的中確率32%なら期待倍率の範囲は「0.32×4組最小オッズ÷4」〜「0.32×最大オッズ÷4」。上限が1未満なら仮説上は配当不足、下限が1.15以上なら研究用の購入候補と表示。**この入力確率は自動で校正されない**ので、購入推奨を保証しない。
- 収益性は、別途校正した3連複の組確率と、実際の発走前オッズが揃って初めて正式判定できる。単勝オッズを3連複のオッズに変換しない。
- 結果はレース後に公式の3連複払戻を別途登録。外れの払戻0円も記録し、見送ったレースも仮購入として回収率を集計。
- 結果を登録しても発走前の判定は変えない。

## ご注意

**このアプリは売買執行ツールではなく、判定研究用の記録ツールです。**

発走前取得時のオッズは、投票締切時のオッズ・実際の払戻を保証しません。netkeibaの非公開APIの仕様変更や取得制限により動作しないことがあります。現在の実行環境は外部ネットワーク接続が制限されているため、実際のnetkeiba通信は未検証です。APIレスポンスを模したサンプルでローカル単体試験を行っています。

`data/odds_research.sqlite` に追記保存されます。Streamlit Cloudでのアプリ再デプロイ・環境再起動時にデータが消える可能性があります。必ず「全履歴をZIP保存」を使って、外部ストレージに保存してください。永続ストレージに置く場合、環境変数`JRA_ODDS_DB_PATH`でパスを指定できます。

同着・返還・取消などの特殊なレースは、通常の払戻率計算ではなく別処理が必要です。

## 合格基準

実際の未使用レースで、**購入側回収率100%超と見送り判断の再現性**。2025・2026年の過去データを使った基準探索は合格の根拠としません。レース前から同一の購入ルールを固定してください。

## 組確率の参考計算（追加）

モデル予測CSVに全馬の`top3_probability`が収録されている場合は、選択4頭の3連複4組の近似確率を「各馬の周辺3着以内確率に合わせた最大エントロピー仮定」で計算し、4組の期待回収率の参考値を表示します。**過去の2025〜2026年検証でこの近似法の組確率の校正が十分ではないことが分かっています。** あくまで未校正の研究指標であり、期待値100％を超えても利益の実証にはなりません。

確率なしの予測CSV、あるいは指定済み4頭を手動入力した場合も、3連複4組と全組オッズの固定保存は可能です。

ZIPバックアップは、このアプリの「バックアップZIPを再読込」から追加復元できます。復元時も既存の日時付き記録・公式結果を上書きしません。

## デモファイルについて

`sample_prediction_format.csv`と`DEMO_SYNTHETIC_*.json`はすべて架空の数字です。実際のオッズではありません。使う場合はJSON読込モードでのみ記録され、時刻検証不可とされます。**デモの数値を馬券購入の参考にはしないでください。**

スナップショットごとに初回の4頭選択、モデルファイル指紋、BOX確率、購入判定の余裕率15％は固定されます。毎回のオッズが変わっても同じ4頭のまま記録し、人気上位7頭から外れた場合はその事実を記録して見送りにします。
